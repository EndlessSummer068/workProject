# BUILD_PLAN.md — 任务与验收（当前关卡：L01）

## 全局 DoD（每条任务"完成"前逐条核对）

1. 项目能运行、无报错（`godot --headless --import` 退出码 0 / 编辑器无红字）；
2. 该任务验收标准全部通过；
3. 文档已按 AGENTS.md §2 顺序更新（GAME.md → TECH.md → 本文件）；
4. 提交信息合规：`[Pn][L01-xx] 一句话`（前缀=任务编号）；
5. 一条任务 = 一次 commit；
6. 玩法数值唯一来源 = GAME.md §4（TECH.md §8）。

> 字段固定：编号｜任务｜优先级(P0/P1/P2)｜类型(功能/资产/音频/重构/文档)｜依赖｜状态(待办/进行中/完成/阻塞)｜验收标准｜提交记录。
> 验收格式：**操作 X → 期望 Y（GAME.md §N 具体字段）**；本计划只拆 **L01**，L02 及以后按关卡另起一节，不塞进本节。
